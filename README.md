# 💾 Nuko-Server

Nuko is an ecosystem. This repository contains Nuko-Server, the server API used to communicate with clients applications.

---

## 🧰 Tech Stack

**Server:**
- TypeScript
- Express
- Socket.io
- JSON Web Tokens (JWT)
- PostgreSQL

---

## 🛠️ Installation

- Clone the repository:

```bash
git clone https://github.com/juan-david-ot/Nuko-Server.git
cd Nuko-Server
npm install
```

- Please request the .env file from the maintainer.

- Configure env variables with the .env file.

---

## ▶️ Usage

### Development

```bash
npm run dev
```

### Production

```bash
npm run build
npm run start
```
